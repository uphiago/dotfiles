# Apps do Windows fora do winget export

`winget import -i winget-apps.json` e `winget import -i winget-extra.json` cobrem quase tudo.
O `winget-extra.json` tem apps instalados por instalador próprio, com IDs conferidos no winget:
Chrome, Discord, WhatsApp, VALORANT (BR) e League of Legends (BR).

Instalação manual:

| App | Como |
| --- | --- |
| NVIDIA App + driver | nvidia.com/drivers (ou `winget install XP8CLZL93F5Z4P`, Store) |
| PredatorSense | Suporte Acer, pelo modelo/serial do notebook |
| HyperX NGENUITY | hyperx.com (a versão da Store `9P1TBXR6QDCX` é a Legacy) |
| Office LTSC Pro Plus 2024, Project Pro 2024, Visio Pro 2024 | Office Deployment Tool + licença |
| Jogos Steam (Atomic Picnic, Irmão do Jorel) | Biblioteca da Steam |
| Teamfight Tactics | Riot Client |
